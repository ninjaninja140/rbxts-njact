# @njact/njact [WIP]

## A Nj.act suite package

@njact/njact is part of the Nj.act (ninjaninja140's react) package suite for Roblox-TS.
This package provides the base elements for UI development, aiming to be as close to raw browser React/HTML base elements.

This package is intended to be part of @njact/theme, which is a package suite comprised of basix-ui, nobix-ui, basix-themes, nobix-themes, nincn-ui, interkit and uikit. `njact` is the new-generation, direct replacement, for `nn140-uikit`.

This package will eventually also be a core part of `@njact/sailboat`, which is intended to become a recreation of TailwindCSS in Roblox TS React/Nj.act.
